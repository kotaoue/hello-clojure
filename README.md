# hello-clojure

A small repository for learning Clojure.

## Environment setup

### Requirements

- Java

    ```sh
    java -version
    ```

- Clojure: <https://clojure.org/guides/install_clojure>

    ```sh
    clojure -Sdescribe
    ```

## Hello World sample

This repository includes one sample program:

- `src/hello_clojure/core.clj`

Run it:

```bash
clojure -M -m hello-clojure.core
```

Expected output:

```text
Hello, world!
```
